# @botanical/web

Vite + React + TypeScript client for Botanical.

v0 is a design-complete shell: passcode login, required profile pick, agents, streaming chat, and a self-host / SaaS badge. API calls are placeholders in `src/lib/api.ts`.

```bash
cd packages/web
bun install
bun dev
```

Open http://localhost:5173. Any passcode of 4+ characters unlocks the mock session.

See [docs/UI.md](../../docs/UI.md) for the design system.
